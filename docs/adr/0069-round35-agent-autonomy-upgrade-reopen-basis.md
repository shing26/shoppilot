**三、覆盖 ADR 0008 / 0036 两个数字的依据——三账**（归类：所有者政策覆盖，round23 共识）：

- **能力账**：4 = 三步链（ADR 0008 里被截断的「查订单→查物流→改地址」）+ 1 反思余量（决策 4 要求
  反思占轮预算，不留格它没有位置）。
- **安全账**：安全职责已由**每步守卫**（归属 / 溯源 `isUntrustedOrderNo` / 幂等 / 审批闸）与**循环外
  确定性出口**（限流 / 情绪门 / 显式转人工 / 请求级回放 / 空召回 ADR 0068 / 角色拒）承担，与循环长度解耦——
  ADR 0036「长链 = 用户诉求不聚焦」的担忧由槽位追问与这些出口接管。
- **有界账**：4 仍是硬上限，超限照旧 `TOOL_ROUNDS_EXHAUSTED` 落工单，最坏模型调用有界
  （≤4 工具轮 + 预算检查 1 次 + 纠偏 1 次）——ADR 0008 的「可预算」论证格式沿用、**数字换代**。
- **形式**：一个旋钮 `shoppilot.agent.max-tool-rounds`（`@Min(1)` 保留），默认值进 yml；
  ADR 0036 的「`plan.length ≤ N` 与工具轮硬上限是**同一条边界的两种表述**」照旧成立。
- **既有 ADR 原文一字未改**（0008 / 0036，以及 0037 / 0047 / 0067 / 0068 等全部）。换代指针写在本 ADR、
  spec v2 与 tracker 三处——**指针不许追加到既有 ADR 顶上**（B7 窗口约定，round23 票 69 先例：
  给既有 ADR 加一行指针会被「本轮窗口未碰内容级禁面」当场判红）。

**四、失败三分法与反思语义（收敛 137/138，机读细节在 spec v2 §2 与各票）：**

- 反思规则六条：**触发** = 读工具返回 `TIMEOUT`/`UNAVAILABLE` 且该工具③类反思次数 < 1 且还有轮预算；
  **动作** = 失败事实回填 + 失败上下文说明 → 下一轮重规划（**占** 4 轮预算、不加轮次；失败的那一枪
  不进 `plan[]`）；**上限** = 按工具合计 **1 次**（第二次无论哪种③失败一律按原语义收口 =
  `TOOL_UNAVAILABLE` + 落工单）；**写工具不反思**；**模型输出层错误与 LLM 失败不反思**；
  **反思不得绕闸**（闸判定先于反思）。
- gold 的机器锚：①/②类照旧中止，`PLN-ABORT-*`（`plan-aborted` 前缀）形态原样保住；
  反思只发生在③类、且失败枪不进 `plan[]`——`eval_task.py` 取第一个同名工具步的不变量不受扰动。

**五、四件外部面（收敛 139/140/141，公开口径零变动）：**

- **观测**：`AgentResult.PlanStep` **只增字段** `attempt` + `reflection`；新 counter
  `shoppilot_reflection_total{outcome="triggered"|"exhausted"}`（指标名 55/57 → **56/58**，README:402 + EVIDENCE 同步）；
  trace 新增**小写头**行 `reflection=<tool> attempt=<n>`；**SSE 不加事件**；
  **`FallbackReason` 不 +1**（README「枚举 10 / 降级 9」/ EVIDENCE / architecture-faq 零同步）。
- **提示词**：v1.2.0 = **第 4 条一句扩写**（反思配合折进现条，保持 11 条）；历史版本保留；
  **预算数字不进提示词**（`SHOPPILOT_AGENT_MAX_TOOL_ROUNDS` 是唯一源）。
- **评测**：`eval/cases-part10-autonomy.jsonl` / `kind: autonomy` / 30 条 = 15（动态规划）-10（反思）-5（超限）；
  新模块 `scripts/eval_autonomy.py` **单独成列**（ADR 0050 家法）、不并 `eval_suites.py`、
  **不进 `GOLD_CASE_FILES`**；0 token 夹具自检折进 CI 既有套件步（**仍九步**）；
  成本列读 `shoppilot_llm_tokens_total` 增量（不读响应 token 字段，见 §六）。
- **预算**：`SHOPPILOT_LLM_DAILY_TOKEN_BUDGET` 260000 → **600000**（`.env` 值 + `.env.example` 注释；
  **ADR 0012 的闸门本体保留**）。依据 = 票 140 的 AFK 实测：一次全跑 ≈ 29 万 + 一次复跑 = 58 万。

**六、本轮内的两条登记债（不冒充政策覆盖）：**

- **R11**（写动作守卫没吃行业门：`expectedWriteTool`/纠偏条件不看 `domain`，非电商租户会被纠偏
  诱导谎报「已提交」）→ 票 **146**。依据 = **ADR 0031 第 10 行的事实性修正/门禁一致性豁免**：
  同一道行业门在 `toolsFor` 与网关派生两处已吃，守卫漏了同一道——这是漏吃，不是新功能。
- **R12**（响应里的 token 字段三处缺口）→ 票 **145**。依据 = 该登记债自己的触发条件
  「实现轮动观测面（票 139 的落地清单）时顺手补」。

**七、不并入本轮**（登记与触发线照旧）：U7（180 条 gold 活体重跑——预算换代后其「额度侧前置」成立，
但重跑与否仍是独立决策，gold 面一字不动）；三条真缺陷（语料矛盾 / 退款读回 / 取消出口）；
跨会话记忆 / 知识反向沉淀。

Considered Options:

- **保持 ADR 0008 的 2 轮、用「拆成两轮对话」替代三步链**：否决。这是 ADR 0008/0036 当年的建议，
  前提是「长链 = 用户诉求不聚焦」且工具轮不可预算；三账重估后两条前提都变了（§三），
  且产品诉求已从面试作品变为可运行的系统雏形（ADR 0052）。
- **4 步独立成第二个校验面（轮与步分开取值）**：否决。与 ADR 0036 的「同一边界两种表述」直接相撞、
  没有产品理由，还多一个会各自漂移的旋钮；谁要单独限计划长度，是新决策，回来另开票。
- **反思对所有失败开放（含闸拦下的调用）**：否决。闸的意义就是不给「换着花样绕闸」留门——
  归属拒绝后换单号重试即撞库/越权探测、终态拒绝换参重试即绕业务规则、审批闸重发即绕放行、
  幂等回放重执行即重放写动作。跨租户串号 0 次不可被威胁。
- **反思按「同型失败」（同 status）计数而不是按工具合计**：否决。按工具合计更严、更简单、更难绕；
  同工具第二次③失败无论哪种一律收口。
- **写工具也允许反思**：否决。结果不明时自动重试资金动作风险大于收益；**改参重试绕开两层幂等**
  （派生 token 含参数，新参 = 新动作）；同参重试虽被幂等兜住，但反思不保证同参——不赌。
- **把反思做成提示词驱动**：否决。闸 / 中止 / 反思的判定在状态机（138 的规则六条）；提示词只管
  表达层（收到失败上下文后怎么做人话与再试），教 ①②③ 分类反而给模型「讨价还价」的空间。
- **反思观测走 SSE 新事件 / `FallbackReason` +1**：否决。两次 `tool_result` 已把「同一工具失败后
  又成功」摆在流上；动枚举要同步 README/EVIDENCE/architecture-faq 三处生成物，而 counter 的
  `outcome` 标签已能区分触发/用尽。
- **把 4 轮 / 4 步写进提示词**：否决。配置是唯一源；env 调档时提示词不漂移——v1.1.0 从未写过数字，
  第 9 条「轮次有限」原文不动。
- **拆两轮（机制轮 + 评测轮）**：否决。这是一条竖切：评测读数必须与 v1.2.0 同一轮归因
  （与 v1.1.0 不可混比），拆开会出现「新机制 + 旧提示词读数」的混账；且 0 token 部分
  （143-148）与花钱部分（149）在同一轮内分票已经足够隔离。
- **用响应里的 token 字段做评测成本列**：否决。R12 实测三处缺口（4 轮用例上报 2,811 vs 计费 11,338）；
  成本列读指标增量，响应字段的补齐本身走票 145。
