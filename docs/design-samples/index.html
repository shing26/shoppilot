前端重设计 · 三版高保真样张

ShopPilot：从演示台到真实产品，三条不同的路

三版不是配色差异，而是为谁做、解决什么问题的差异。每版只做 1 页核心界面，均带业务态切换（正常 / 加载 / 空 / 错误 / 权限），可直接点击体验。样张为纯静态文件，不连后端，所有 ID 为示意值。

重要前提 ①：项目已在 docs/PRODUCT_POSITIONING_DECISION.md 锁定路线 A（可信 Agent 运行时），并明令停止"为看起来像产品而加视觉话术"。V3 与该定位一致、零后端改动；V1/V2 若要真落地，需先解决数据留存与真实身份两个后端前置条件。
重要前提 ②：当前工作树里 round 51 / 票 219 已完成一次 UI-only 的产品化改造（买家端 + 坐席台，未提交），V1/V2 样张是在那次改造之上的方向探索，不是"从零重设计"；三版是设计取舍对比，落地时须与 219 的既有改动合并考虑，不要直接覆盖。

怎么看这三份样张

  1. 每页顶部有一条业务态切换条，点不同状态看同一页面在真实业务下的表现——这是判断"是否只是 demo"的关键。
  2. 样张内容尽量取仓库真实资产：规则块 ID 来自 knowledge/，Agent 三段文案来自 format.ts，指标与未达成项来自 docs/EVIDENCE.md / STATUS.md。
  3. 三版共用 frontend-shared/src/tokens.css 的设计令牌，不引入新配色，差异在信息架构与内容组织。
