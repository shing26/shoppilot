## 7. 纪律与坑

- **不要改判据来变绿**：`intent`、`tool`、`toolStatus`、`fallback`、`ticket` 都是行为断言；答案同义组只放宽表述，不降低事实要求。

- **不要提交 `.env` 或 API key**；`.env.example` 必须保持 `sk-replace-me`。
- **不要删除历史 `eval/results` 报告**；新报告只增。
- **ingest 半途中断会留下部分纪元**：先确认 `epoch` 与 ES 文档数一致；不要手工 bump 去“凑”可用索引。
- **Docker Desktop 空闲会停**：出现 `dockerDesktopLinuxEngine` 连接失败时先拉 `D:\Docker\Docker Desktop.exe`，等 30–60 秒。
- **local 档 Ollama 是单点瓶颈**：embedding 超时会变成 `degraded`，此时 golden 失败不是代码回归；先重启 Ollama 再跑。
- **CI 不跑 golden**：它需要活体栈；CI 只守 640 条 JVM 测试、门禁、前端产物。
