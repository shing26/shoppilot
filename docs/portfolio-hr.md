# ShopPilot HR 速览

> 一屏读完。要核数字进 [`../README.md`](../README.md) 的指标表，要核来源进 [`EVIDENCE.md`](EVIDENCE.md)。

- **项目定位**：高并发智能客服与业务网关，面试作品，单机可复现（一条 `up.ps1`，干净克隆实测 205 s）。
- **形态**：**四模块**多服务单仓（`tool-api` 契约 / `biz-mock` 业务与身份 / `ticket` 工单与坐席 / `gateway` 对话编排），
  Java 21 虚拟线程 + Spring Boot 3.3.5，约 2.96 万行。**三个前端入口**：运维调试台 `/`、坐席工作台 `/workspace/`、买家中心 `/buyer/`（Vite+Vue3）。
- **业务问题**：热点重复不进模型、对话能落业务、语义缓存不串号、依赖故障可降级、**结单结论能送回原渠道**。
- **核心结果**：命中路径 P99 **22 ms**（200 并发）；Token 节约 **62.4%**；虚拟线程 400-800 并发 **+64%**；
  混合检索 hit@5 **10/10**、MRR **1.000**（融合）/ 0.875（BM25）。
- **工程取舍**：缓存放在意图判定之后（放弃一部分拦截率换零串号）；工具循环硬上限 2 轮；阈值 0.95 而不为召回放宽。
- **诚实度**：缓存拦截率 74%（判据 80%）、吞吐 1013 QPS（判据 1200）、TTFT 690-1499 ms（判据 500 ms）——**三条未达标保留实测值与归因，不换口径刷绿**。
- **可核查性**：**59 篇 ADR**、98 张开发票、**451 条 JVM 测试**、GitHub Actions **九步**门禁全绿（覆盖率棘轮 / 评测判据自检 / 检索录放门 / 前端产物逐字节校验），全部 0 token。
- **技术关键词**：Java 21 / Spring Boot / Function Calling / RAG（Qdrant + ES + RRF）/ Redis（缓存 + Streams 事件骨干）/ SSE / Flyway / Vue 3。
- **最值得问我的**：**事件骨干从未在真实 Redis 上跑通，而守它的门禁是绿的**——三个静默缺陷靠 `MONITOR` 抓包定位，复盘见 [`incident-2026-10-silent-failure-modes.md`](incident-2026-10-silent-failure-modes.md)。
