# Teaching Notes

- 用户要求先做独立 cold-read，再建立八站掌握路线；cold-read 只证明三分钟入口可读，不证明八站已掌握。
- 默认用中文教学，偏好证据优先、短课、可复现命令和明确的红值边界。
- 每站固定五段：`Decision`、`Reproduce`、`Three questions`、`Failure symptom`、`Evidence link`。
- 答案要能说出口，不只是能读懂；每课用 `<details>` 做主动回忆，先回答再展开。
- 不把 README 的大指标表复制进课程；课程只保留讲法所需的少量数字，并链接到 `README.md` 与 `docs/EVIDENCE.md`。
- v1.0.0 已冻结。教学不得变成功能开发；真实面试反馈只进台账，达到 ADR 0031 门槛才重开。
- 最难取舍按“缓存放在意图之后”训练，因为它主动用命中率换跨意图正确性，和项目的安全边界最相关。
- 所有练习都要区分三件事：判据是什么、实测是多少、限制在哪里。只背数字不算掌握。
- 面试讲述顺序固定为：问题 -> 决策 -> 取舍 -> 证据 -> 限制。不要从技术栈清单开场。
