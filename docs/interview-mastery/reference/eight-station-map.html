八站面试速查卡

用途：面试前 15 分钟快速定位。每站先讲“为什么会这样”，再给源码和命令；红值必须和判据、归因、限制同时出现。

1. 入口与身份

决策：身份只认签名 JWT；客户端 tenant/customer 一律不采信。dev 默认值只在回环地址合法。

首读：AuthFilter / JwtService / TenantContext / DevDefaultsPolicy

故障：按请求头换租户仍能读到别家数据；绑定 0.0.0.0 仍靠默认密钥启动。

2. 意图三级级联

决策：T0 规则 → T1 质心 → T2 模型，不额外买一次分类请求；动作优先，UNKNOWN fail-closed。

首读：TriageEngine / T0RuleLayer / T1CentroidLayer

故障：动作请求被当作政策缓存；UNKNOWN 进入 L1/L2；T1 与 L2 各算一次向量。

3. 两级缓存与穿透合并

决策：缓存放在意图之后；L1 精确 key，L2 语义 + 0.95 + 极性守卫；只有合格答案可写回。

首读：CacheService / L1Cache / L2SemanticCache / PolarityGuard / SingleFlight

故障：反义问句互命中；命中率虚高但答案在复读道歉；冷缓存把远程 embedding 放大。

4. 检索与入库

决策：Qdrant dense + ES BM25，RRF 融合；Markdown 按二级标题切块，重跑幂等 upsert。

首读：HybridRetriever / EmbeddingClient / MarkdownChunker

故障：一路挂了被当成“库里没有”，负缓存把抖动固化成 60 秒转人工。

5. Agent 编排与工具

决策：10 状态有界状态机；工具循环最多 2 轮、缺槽最多追问 1 次；写操作受幂等守卫。

首读：AgentStateMachine / ToolDispatcher / shoppilot-tool-api

故障：自由循环不终止；缺槽猜参数；重复退款；工具失败变成 500 而不是可解释回复。

6. 业务中台与隔离

决策：biz-mock 独立进程；共享表做行级租户隔离；归属谓词 + DB 唯一约束 + 状态前置。

首读：BizMockService / bizmock/repo / bizmock/domain

故障：跨店查到订单；50 并发同 token 生成多条退款；非法工单状态被接受。

7. 降级、限流、可观测

决策：可降级依赖不进 readiness，另立 deps；限流做租户 + 买家/IP 双维；降级必须可枚举、可落单。

首读：FallbackService / RateLimitService / RuntimeStateMetrics

故障：依赖一挂 readiness 摘流量；每个 429 都新建工单；只有事件没有可查工单。

8. 量化与门禁

决策：报告由产物生成，strict 缺证据即红；CI 只承诺干净 runner 构建 + 221 JVM 测试。

首读：run-acceptance.ps1 / run_loadtest.py / build_loadtest_report.py / EVIDENCE.md

故障：文档手抄数字与 CSV 漂移；聚合值遮住分意图红值；把本机全量验收说成 CI 覆盖。

三条必须先排好序的口径

最难取舍：缓存放在意图之后。它主动放弃一部分拦截率，换取跨意图和含实体请求不串号。

正向数字：命中路径 P99 22 ms；Token 节约 62.4%；虚拟线程 400-800 并发收益 +64%。每个都带模式、并发和作用域。

红值：拦截率 74-78% < 80%；吞吐 1013 QPS < 1200；未命中 TTFT 690-1499 ms > 500 ms。不能只报红值，也不能换口径洗绿。
