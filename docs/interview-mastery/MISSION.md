# Mission: ShopPilot 八站面试掌握路线

## Why
用 ShopPilot 作为可复现、可追问的 Java 后端主项目，准备真实面试；目标不是背项目介绍，而是能在 60 秒和 3 分钟两种长度下讲清设计取舍，并在追问时把每个结论落回源码、命令和证据。

## Success looks like
- 能不看稿讲出八个生命周期站点、10 状态主链路和“缓存后置、工具两轮、阈值加极性守卫”三项核心取舍。
- 能为每站复现至少一个命令，并解释输出说明了什么、没有说明什么。
- 能把三条未达标指标连同归因、限制和历史读数一起讲清楚，不用聚合绿值遮住红值。
- 面试后能把真实问题写进 `docs/interview-feedback.md`，按 ADR 0031 决定是否重开工作，而不是继续无边界扩项目。

## Constraints
- 用中文练习，答案必须先给决策，再给证据，最后给边界。
- 以仓库当前 `v1.0.0` 冻结线为准，不新增功能，不改 ADR、阈值、gold、指标分母或验收判据。
- 所有技术结论必须能回到本仓源码、报告或一手文档；作品集只作入口，不替代证据。

## Out of scope
- Round16+ 功能、生产化、部署形态、告警系统、工单持久化和跨实例验证。
- 泛化的 Java 八股大全；只补回答 ShopPilot 追问所缺的知识。
- 把项目重讲成“大模型自主 Agent”或重写核心架构。
