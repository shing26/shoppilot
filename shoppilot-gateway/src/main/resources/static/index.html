链路示例
  1. 买家带订单提问 问题、订单上下文与店铺政策一起进入会话
  2. 在线客服核验 先核订单归属，再按命中条款回答；办理类动作不替用户猜
  3. 转人工，落一张工单 进入坐席队列，优先级、来源与 SLA 都可筛选
  4. 坐席结单，结论回到买家 领取与结单署名取自账号，处理记录可追踪

这是流程示例，不展示虚构的处理时长或在线人数。
