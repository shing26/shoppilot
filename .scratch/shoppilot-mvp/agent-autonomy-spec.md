## 2. 计划轮廓（草，拆票时细化）

- ADR 0052：开轮依据（所有者政策覆盖）+ 失败三分法语义。
- 票（草，69 起）：
  1. 循环/计划预算可配 + 计划生成（模型自定步数 ≤4）；
  2. 失败分类 + 反思分支（带失败上下文重规划；观测面加反思标记与 attempt 序号——判据要有得判）；
  3. 新评测集 part9（动态规划 ~15 / 反思 ~10 / 超限收口 ~5；judge 新列**不并总分**，ADR 0050 先例；part9 不进 `GOLD_CASE_FILES`）；
  4. 叙事换代（README agent 段 / interview-qa 重生成 / DELIVERY / CHANGELOG）+ 收口。
- 顺序：机制层全 JVM 桩（0 token，先钉契约）→ 评测集与判据 → dev 活体验证 → 叙事与收口。
- 预算预估：dev 评测 10–20 万 token（每条 3–6k）。

## 3. 风险（先登记，收口逐条对）

- local 3B 大概率跑不出 4 步链 → `plansteps` 红可能更红，**判据不动、照登**（round20 家法）。
- dev 评测烧真钱；预算抬多少以试跑实测为准，不拍脑袋。
- 反思是新的模型方差源 → 判据必须可枚举（触发/不触发/次数上限），不能判"看起来聪明"。
- 失败分类边界漂移会打现有 gold → JVM 钉死三分法的每一格（变异对照）。
- 本机资源：矩阵/活体仍受 16G 内存与显存争抢限制（见 tracker 2026-09-28 登记项）。
