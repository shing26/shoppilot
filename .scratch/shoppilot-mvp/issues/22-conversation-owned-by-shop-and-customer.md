# 22 — 会话按「店铺 + 买家」归属

**What to build:** 让一段会话真正归属于「店铺 + 买家」两者：别人的会话 id 载不出别人的对话、写不进别人的会话、也续办不了别人没办完的待办动作。页面上换身份之后旧气泡一并清掉。落实 ADR 0025。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

**Verify:** 单测面三条跨买家用例 -> 页面上换身份问一句可 demo 出「载不出对方上下文」-> 起栈与三条演示仍绿 -> 零额度。

- [ ] 外置会话状态的键含买家归属，形状按 ADR 0025
- [ ] 跨买家拿同一个会话 id 载入，得到空会话（缺陷本体）
- [ ] 跨买家写入不落到对方会话里，双向不污染
- [ ] 跨买家不得续办别人的待办动作：对方的参数既不得进入 prompt，也不得被拿去发动作——本票最能打的一条
- [ ] 订单行侧既有守卫一字未动：按「店铺 + 买家」拦的查询与含买家的幂等键照旧
- [ ] README 隔离那行只写本票真修掉的边界（上下文可见性），不许升格成「跨买家隔离已达成」
- [ ] 词汇表里「会话」与「待办动作」两条的定义与代码行为一致（冲突以本票为准改文档，不是反过来）
- [ ] 调试台换身份后清空对话区，不再显示归属上一位买家的气泡
- [ ] 旧键不迁移，靠过期自然走；不因键形状变化而报错
- [ ] 零额度；审计项数保持 95
