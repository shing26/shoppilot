# 183 渠道会话：提示音

**Status:** implemented（2026-10-29）

**Claimed by:** zcode session 2026-10-29

> 通知之外再加一声轻提示，坐席不用一直盯角标。

## 已实现

- 渠道页新增“开启提示音”开关，首次点击创建/恢复 AudioContext（满足浏览器手势要求）；
- 开关存 localStorage；
- SSE 新买家消息（unread>0、最后 role=user）且当前会话不可见时播放 880Hz 短音；
- 与通知独立：Push 订阅、页面通知是否开启都不影响声音；
- 声音不可用/被策略拒绝时给文案，不阻塞通知。

## 验证

- 前端 typecheck/build 通过；
- 全量 JVM 仍为 733 / 124。

## Non-goals

- 自定义音效/音量；
- 页面关闭后的声音（浏览器不保证）。

## Handoff notes

**关键决策**

1. 用 WebAudio oscillator，不引入音频文件；
2. 用户点击后才创建 AudioContext，避免自动播放策略拦截；
3. 声音与通知/Push 解耦，任一通道失败不影响另一个。

**三个现场追问**

1. 为什么需要点击？浏览器自动播放策略要求用户手势；
2. 页面关掉还能响吗？不能，声音是页面内 WebAudio；
3. 会不会和通知重复？只是听觉提示，不替代通知。
