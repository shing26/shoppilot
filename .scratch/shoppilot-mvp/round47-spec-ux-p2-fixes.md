## 2. 逐票判据

票 195：

1. 知识视图反馈票显示「有用 / 没用」，不再出现 `UP` / `DOWN`；退款决策路径显示
   「待审核 / 已放行（待通道）/ 已驳回」，不再出现 `PENDING_REVIEW`；渠道会话卡片显示
   「智能助手 / 坐席接管」，不再出现 `BOT` / `AGENT`；买家订单服务标显示
   「七天无理由 / 生鲜保障」，不再出现 `SEVEN_DAY_RETURN` / `FRESH_GUARANTEE`。
2. 四个映射遇到未知值原样显示（不吞、不显示空白）。
3. 带令牌的请求返回 401 时，两端自动回到登录面并写明「登录已失效」；不带令牌的登录
   请求 401 不触发登出钩子。SSE 入口返回 401 同样触发。
4. `--ink-3` 对 `--bg` / `--line` / 白底的对比度分别为 5.46 / 4.67 / 6.06，均 ≥4.5；
   其余颜色令牌不变。

票 196：

1. 390×844 下「退出」「刷新」「问问这单」与订单/工单 tab 的可点击高度 ≥40px。
2. 390×844 下点「问问这单」后视口回到对话主区顶部（聊天区），不是在侧栏原地等待。
3. 对话容器的可访问性语义是 `role="log"`，`aria-atomic="false"`，只播报新增内容。
4. 复核结论：游客转人工后消息指向「我的工单」，侧栏工单页签能读到该单，不再存在
   「游客模式不展示工单」文案；本项**不改代码**，证据落 Handoff。

票 197：

1. 队列筛选到某档后，右侧详情只显示该档内的工单；结果为空时详情清空。
2. 未领取工单的「处理完成」禁用，并显示「先领取再处理」；领取后恢复可用。
3. 390×844 下导航为三列两行（不是 6 项单列），导航项高度 ≥40px，队列在首屏可见。
4. 顶栏「刷新队列」「退出」在 390×844 下可点击高度 ≥40px。
5. 知识五步条的「人工复核」用服务端 REVIEWED 总数：附稿后「可附稿」列表减少，
   但「人工复核」这一步的计数不回零。

票 198：

1. 有请求流过之后，质量报表的 `maxSeconds` 不随时间窗衰减到 0；同一进程内它只增不减。
2. `count` / `meanSeconds` 口径不变。
3. 无流量时 `maxSeconds` 仍为 0（「还没有发生」是合法读数）。
4. gauge 缺失时回退 `Timer.max()`，不抛错（老注册表/测试替身）。
5. JVM 新增用例：累计最大在多次记录后取最大；sidecar 优先读 gauge。

## 3. 本轮不改

- 验收判据、阈值、gold、指标分母。
- 后端工单状态机（`OPEN → RESOLVED` 仍是合法迁移）。
- 退款/复核/知识/渠道的业务语义。
- 既有指标的标签与含义（只新增一个 Gauge 名）。
- 移动端导航的折叠式重设计（只改排列与高度）。

## 4. 登记不执行

1. **后端 `resolve` 的领取前置**：`WorkItemService.resolve` 对 `assignee == null` 放行，
   与「只允许领取人结单」的注释不完全一致。触发 = 有人需要从 API 侧保证「未领取不可结单」，
   或演示数据出现无法归责的结单。
2. **完整无障碍审计**：本轮只修 `aria-live` 粒度与三处对比度/点击目标；
   `aria-live` 之外的键盘路径、语义角色与读屏全流程不审计。触发 = 无障碍进入
   产品演示或外部验收清单。
3. **401 的令牌续期**：仓库没有 refresh token 端点；本轮只做「自动回登录面」。
   触发 = 引入续期或单点登录排期。
4. **移动端导航折叠/抽屉化**：三列两行已让队列回到首屏；是否进一步收进汉堡菜单
   取决于是否继续增加视图。触发 = 工作台视图从 6 个继续增加。
