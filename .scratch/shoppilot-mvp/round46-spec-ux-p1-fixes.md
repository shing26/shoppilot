# round46：真实用户走查的七条 P1 缺陷修复

## 0. 本轮要补的那一格

```text
买家页
  ├─ 游客态：订单 / 工单不再隐藏（令牌能读到的就展示）      ← 票 192（P1-1）
  ├─ 刷新：对话与会话 ID 从 sessionStorage 恢复              ← 票 192（P1-2）
  ├─ 输入法：组合中的回车不发送                              ← 票 192（P1-4）
  ├─ 订单深度卡：只留侧栏一层滚动                            ← 票 192（P1-6）
  └─ 退出：先中止流，再清状态                                ← 票 192（P1-7）

三处弹层：Esc 关闭 / Tab 圈在层内 / 焦点进入并归还            ← 票 193（P1-5）

工作台
  ├─ 复核完成 → 顺手结掉 REVIEWED 工单                        ← 票 194（P1-3）
  ├─ 复核队列支持 status=REVIEWED，刷新后仍可附稿              ← 票 194（P1-3）
  └─ 复核单详情「去复核这条反馈」跳知识视图                     ← 票 194（P1-3）
```

## 2. 逐票判据

票 192：

1. 游客态进入 T001：侧栏出现 C001 的真实订单（非空）与工单计数；转人工文案不再写「游客模式不展示工单」。
2. 发一问后刷新：消息、回答与会话 ID 都还在；再点踩仍能投到同一会话（网关按 `conversationId` 回指）。
   换店或退出后刷新不再恢复上一家的对话。
3. 中文输入法组合中的回车不发送；组合结束后的回车正常发送。
4. 展开订单深度卡：整卡随侧栏单一滚动条滚动，卡片内部没有第二个滚动区。
5. 流式中点「退出」：`/chat/stream` 请求被中止（请求列表出现 aborted/canceled），页面回到登录门。

票 193：

1. 三个弹层打开后焦点在层内；Tab/Shift+Tab 不跑出层。
2. Esc 关闭，关闭后焦点回到打开它的按钮。
3. 点击遮罩仍可关闭（既有行为不回归）。

票 194：

1. 点踩生成复核工单后，在知识视图复核该条：工单变为 `RESOLVED`，`feedback.review_ticket_id` 有值。
2. 刷新工作台后 `status=REVIEWED` 的反馈仍在「已复核 · 可附稿」里；附过稿的不再重复出现。
3. 复核队列默认行为不变（不传 `status` 仍是 PENDING）。
4. 工单队列打开复核单，点「去复核这条反馈」进入知识视图。

## 3. 本轮不改

- 复核内容本身（不自动改写、不生成正文，ADR 0039）。
- 结果回流、退款、渠道、质量视图。
- 验收判据、阈值、gold、指标分母。
- P2 清单（见 ADR 0081 Consequences）。

## 4. 登记不执行

1. **历史存量回填**：已复核但工单仍 OPEN 的老数据不做批量结单。触发 = 演示库需要长期保留的
   真实运营数据（而非可重置的演示世界）。
2. **`aria-live` 粒度与对比度/点击目标**（P2）——触发 = 无障碍进入产品演示清单。
3. **401 自动登出**——触发 = 令牌续期或单点登录进入排期。
